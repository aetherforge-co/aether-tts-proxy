AETHER TTS Proxy

Server-side proxy that keeps the ElevenLabs API key off the browser for the AETHER dashboard.

Available Endpoints

POST /api/speak

Proxies text-to-speech requests to ElevenLabs.

Headers: X-Aether-Secret (required)

Body:

{
  "text": "Your text to convert to speech",
  "voiceId": "21m00Tcm4TlvDq8ikWAM" // optional
}

POST /api/storefront-chat

Proxies the Aetherforge storefront's AETHER widget to Google's Gemini API.

Origin: Must be from an allowed domain

Body:

{
  "messages": [
    { "role": "user", "content": "Your message" }
  ]
}
